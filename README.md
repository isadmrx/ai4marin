# AI4Marin Platform

This repository contains a minimal prototype of the AI4Marin platform. It includes:

- **Backend**: FastAPI application with JWT authentication and ship management for shipowners.
- **Frontend**: React + Vite + Tailwind setup with role based login/registration and basic dashboards.

## Development

### Backend
```
cd backend
uvicorn main:app --reload
```

### Frontend
```
npm run dev
```
